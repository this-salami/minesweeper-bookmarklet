# minesweeper-bookmarklet

What is a [bookmarklet](https://en.wikipedia.org/wiki/Bookmarklet)?
Simply, a bookmarklet is a bookmark which stores JavaScript code, rather than a webpage.

## minesweeper
This bookmarklet was made for https://minesweeperonline.com/, and while it can solve many games, it doesn't have statistical analysis, so it doesn't deal with 50/50s or use probability to find the tile with the lowest probability of a mine (Sometimes including 0% chance since the "linking" mechanism wasn't finished). 

Created around 2025 (or 2024), Original Scrimba Link: https://scrimba.com/s0vb5ebufn/head

## ⚠️ Don't run random bookmarklets ⚠️
While bookmarklets are very convenient for client-side enhancements, they have access to webpage data, only run bookmarklets you trust!

Even this one, I wouldn't recommend running until you personally check the code, or until I post documentation explaining my old code.
